# Security policy

Signalbox is in early development and has no production deployment yet.

## Reporting a vulnerability

Please don't open a public issue. Report it through [GitHub private vulnerability reporting](https://github.com/ayenisholah/signalbox/security/advisories/new).

Include what you found, how to reproduce it and the impact you expect. You'll get a response as soon as the maintainer can review it.

## Scope

The code in this repository, including its infrastructure definitions and workflows.
